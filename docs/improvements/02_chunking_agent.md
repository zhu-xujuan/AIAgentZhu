# Agent: チャンク分割エージェント (Step 2)

## 目的

ページ単位のテキストを検索しやすいサイズ（800-1500文字）に分割する。

## ファイル

- 実装: `services/agents/chunking_agent.py`
- テスト: `tests/test_chunking_agent.py`

**注意**: このエージェントはルールベースのみ（LLM統合なし）

---

## 入力

```json
{
  "pages": [
    {"page": 1, "text": "ページ1のテキスト..."},
    {"page": 2, "text": "ページ2のテキスト..."}
  ]
}
```

---

## 出力（JSON厳守）

```json
{
  "chunks": [
    {
      "chunk_index": 0,
      "page": 1,
      "section_title": "見出し|null",
      "text": "本文",
      "char_len": 1200
    }
  ]
}
```

---

## チャンクサイズ仕様

```
MIN_CHUNK_SIZE = 800文字
MAX_CHUNK_SIZE = 1500文字
TARGET_CHUNK_SIZE = 1200文字（最適）
```

---

## 分割アルゴリズム

### 優先順位（高→低）

```
1. 段落区切り（\n\n）
2. 単一改行（\n）
3. 文末（。．.!?！？）
4. 句読点（、，,；;：:）
5. 空白（スペース・タブ）
6. TARGET_CHUNK_SIZEでの強制分割
```

### ロジック

```python
1. テキストが MAX_CHUNK_SIZE 以下なら分割しない
2. MIN_CHUNK_SIZE〜MAX_CHUNK_SIZE の範囲で分割点を探す
3. 優先順位に従って最適な分割点を決定
4. 残りのテキストで再帰的に処理
```

---

## セクションタイトル検出パターン

```regex
# Markdownヘッダー
^(#{1,6})\s+(.+)$

# 番号付きセクション
^(\d+(?:\.\d+)*)\s+(.+)$

# 日本語括弧
^【(.+?)】
^■(.+?)$
^◆(.+?)$

# 法的セクション（日本語）
^第[一二三四五六七八九十\d]+[章節条項]\s*(.+)?$
```

**タイトル最大長**: 100文字（超過時は`...`で切り詰め）

## テストケース

### 正常系
- 800文字未満 → 1チャンク
- 1500文字 → 1チャンク（境界値）
- 3000文字 → 2-3チャンク
- マークダウン見出し → `section_title`に抽出

### エッジケース
- 空テキスト → チャンクなし
- 改行なし長文 → 句読点または強制分割
- 日本語・英語混在 → 文末パターンで分割

---

## ルール（厳守）

1. **800〜1500文字**: チャンクサイズ範囲
2. **意味を壊さない**: 優先順位に従った分割
3. **改行整理は可**: 余分な空白の削除
4. **chunk_indexは連番**: 0から開始

---

## 改善ポイント

1. **セマンティック分割**: 意味的まとまりを考慮した分割
2. **テーブル検出**: 表形式データの分割回避
3. **コードブロック保持**: プログラムコードを分割しない
4. **ページ跨ぎ処理**: ページ境界での文章継続処理
5. **オーバーラップ**: 検索精度向上のためのチャンク重複
